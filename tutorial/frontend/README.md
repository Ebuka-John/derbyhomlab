# Frontend lab (Next.js)

Type these files **in order**. Each step is one lesson file.

Work inside the **`frontend/`** folder at your project root (create it in step 1).

If React / TypeScript are new, each step includes a short **Concepts in this file**
table (types, Route Handlers, client components, state). You do not need prior
frontend experience — follow the tables as you type.

## TYPE THESE FILES IN ORDER

| Step | Lesson file | You create |
|-----:|-------------|------------|
| 1 | [01-scaffold.md](./01-scaffold.md) | `frontend/` + `package.json`, `tsconfig.json`, `next.config.ts` |
| 2 | [02-env.md](./02-env.md) | `.env.example`, `.env.local` |
| 3 | [03-types.md](./03-types.md) | `lib/types.ts` |
| 4 | [04-api-route.md](./04-api-route.md) | `app/api/nearest-grit-bin/route.ts` |
| 5 | [05-search-form.md](./05-search-form.md) | `components/SearchForm.tsx` |
| 6 | [06-layout.md](./06-layout.md) | `app/layout.tsx` |
| 7 | [07-globals-css.md](./07-globals-css.md) | `app/globals.css` |
| 8 | [08-page.md](./08-page.md) | `app/page.tsx` |
| 9 | [09-run-and-test.md](./09-run-and-test.md) | `npm run dev` + UI check |

## Before you start

Finish the [backend lab](../backend/README.md) (or at least have FastAPI ready on port 8000).

Keep **PowerShell** at the project root. Every file step uses `New-Item` to create
an empty file, then you open it and **type** the contents.

Then open **[01-scaffold.md](./01-scaffold.md)**.
