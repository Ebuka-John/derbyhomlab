# Frontend 3 — UI

## Concept

- **`SearchForm`** — client component (`"use client"`). Submits to
  `/api/nearest-grit-bins` (same origin). Optional “how many nearest” toggle.
- **`layout.tsx` / `page.tsx`** — shell + page composition.
- **`globals.css`** — layout and form styling (no card-heavy dashboard).

Keep the UI thin: no business rules beyond form validation and display.
